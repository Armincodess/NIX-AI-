## 🕹️ Interactive Features

1. **Hero Rotating Text:** Dynamic cycle through high-signal taglines (*"Understand the codebase."*, *"Trace the architecture."*, *"Verify the answer."*, *"Retrieve the right context."*).
2. **Interactive Nix Playground:**
   - **10 Real CLI Commands:** `ask`, `oracle`, `index`, `search`, `replay`, `blast-radius`, `why`, `health`, `tree`, `doctor`.
   - **Dynamic Query Selectors:**
     - Select from all **9 real architectural questions** tested on Google `zx`.
     - Select from all **6 semantic and lexical queries** tested on Google `zx`.
   - **Three Multi-Angle Subtabs:**
     - **Terminal Output:** Exact CLI stdout, execution time, and formatting.
     - **Retrieved Context Inspector:** Exact files, AST line ranges, and relevance scores.
     - **Source Verification Report:** Grounded checks validating symbols, paths, and 0 hallucinations.
   - **One-Click Command Copy:** Copies the active command directly to clipboard.
3. **External Agent Workflows:** Interactive visualization showing how Cursor, Claude Code, Antigravity, and OpenCode consume Nix context envelopes.
4. **FAQ Accordion:** 10 expand/collapse technical questions answering privacy, indexing speed, MCP support, local embeddings, and drift detection.
